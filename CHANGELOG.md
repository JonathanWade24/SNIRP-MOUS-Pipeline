## [Unreleased]

### Added
- Initial public release (v0.1.0)
- Full pipeline stages m1–m12 (MEG preprocessing, epochs, features, source, waves, stats, reports)
- Optional fMRI coupling stages (m10, m11)
- Optional wave validation stage (m12)
- CLI with `run`, `watch`, `fetch-subject`, `fetch-rdr`, `group`, `bids-convert`, `bids-validate`, `gui` commands
- Streamlit GUI for Neurodesk/JupyterHub
- RDR (repocli) and Cyberduck data fetch support
- BIDS conversion and validation tools
- Comprehensive test suite
- Documentation (README, CONTRIBUTING, AGENTS)
